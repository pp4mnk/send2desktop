**Send to desktop** adds an option to ROX-Filer’s right-click menu so you can place application shortcuts on your desktop.

To install it, open a terminal in the folder containing the script and run:

```bash
bash send-to-desktop.sh
```

To create a shortcut:

1. Open `/usr/share/applications` in ROX-Filer.
2. Right-click the program’s `.desktop` file.
3. Choose **Send to desktop**. Depending on your settings, it may appear under **File**. You can also use **Shift + right-click**.

The application’s icon appears on the desktop, ready to launch. The original program stays in its location; removing the desktop icon does not uninstall it.

You can also use this option on executable programs and scripts.
